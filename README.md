# AetherPMS | 산출물 관리 프로그램 (Project & Artifact Management System)

AetherPMS는 프로젝트 진행 진척률 관리, 산출물 등록, 버전 히스토리 추적, 및 승인/반려 검토 워크플로우를 완벽하게 모니터링할 수 있는 프리미엄 **산출물 관리 단일 페이지 웹 애플리케이션(SPA)**입니다.

별도의 복잡한 백엔드 서버나 Node.js 패키지 설치 없이 브라우저에서 실행할 수 있도록 경량 고성능 구조로 설계되었습니다.

---

2. 마우스로 **더블 클릭**하거나 웹 브라우저(Chrome, Microsoft Edge, Safari, Firefox 등) 창으로 드래그앤드롭하여 즉시 앱을 실행합니다.

## 🎨 주요 핵심 기능

1. **프로젝트 관리 워크스페이스**
   - 새 프로젝트 등록 및 수정 (부서, 프로젝트 매니저, 일정, 초기 진행률 설정).
   - 각 프로젝트별로 단계별 필요 산출물 요구 사양을 **체크리스트(Checklist)** 형태로 추가하여 완수율 자동 계산.
   - 체크리스트 상태와 프로젝트 진척률이 상호 연동되어 수치 자동 업데이트.

2. **산출물 레지스트리 (Registry)**
   - 요구사항정의서, 시스템설계서, 소스코드, 테스트결과서 등 분류별 일원화 관리.
   - 산출물 검토 상태(초안 작성, 검토 요청, 승인 완료, 반려/재작성) 필터 및 검색.
   - 드래그앤드롭 기반의 **첨부 파일 시뮬레이터** 탑재 (실제 파일의 파일명, 파일 형식 및 크기를 파싱해 가상 첨부).

3. **버전 관리 및 승인 워크플로우**
   - 산출물 변경 시 **버전 이력 관리 (Version History)** 지원 (이전 등록 내역과 변경 코멘트, 당시 첨부파일 정보 영구 누적).
   - 관리자가 검토 의견 코멘트를 작성하며 **승인(Approve) / 반려(Reject)** 처리 가능.
   - 특정 버전이 승인 완료(Approved)되면 해당 분류의 프로젝트 체크리스트가 자동으로 체크 처리되어 관리 업무 단축.

4. **대시보드 및 네이티브 SVG 차트**
   - 전체 통계 (총 프로젝트, 등록 산출물, 승인 대기 건수, 평균 진척률) 요약.
   - 실시간 산출물 상태 분포를 표현하는 **네이티브 SVG 원형 도넛 차트 (Circumference 100)** 탑재.
   - 마감 기한이 임박한 산출물에 대해 자동으로 알림 창 및 뱃지 표시.
   - 실시간 활동 기록(Activity Log)을 수집하여 타임라인 형태로 시각화.

5. **데이터 백업 및 복원 (Export / Import)**
   - 브라우저 LocalStorage에 모든 데이터를 안전하게 동기화 저장.
   - 브라우저 캐시 삭제 시 데이터가 유실되지 않도록 **데이터베이스 백업(.json 파일 다운로드)** 기능 제공.
   - 백업된 파일을 다시 불러오는 **가져오기(Import)** 및 초기 샘플 데이터 세트로 돌리는 **초기화(Reset)** 기능 탑재.

## 📁 파일 구조

- **`index.html`**: 애플리케이션의 화면 레이아웃 정의, 다양한 팝업 다이얼로그 모달 구조화.
- **`style.css`**: 다크/라이트 테마 토큰 정의, 글라스모피즘(Glassmorphism) 스타일링, 부드러운 애니메이션 효과 및 반응형 웹 디자인 설계.
- **`app.js`**: 애플리케이션 핵심 비즈니스 로직, LocalStorage 동기화 모듈, 동적 SVG 차트 연산기, CRUD 연동 핸들러 내장.
