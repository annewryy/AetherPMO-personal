## 1. 급여(salaries) — "엑셀 붙여넣기 보조" 방향

**우리가 이해한 방향**
- 급여는 **인사/재무팀이 엑셀로 관리**하고 있고, 그 엑셀에는 이미 **계산 함수가 짜여 있음**.
- 따라서 PMS가 급여를 자체 산정하는 게 아니라, **매월 PMS에서 관리한 내용을 기존 급여 엑셀의 새 시트에 붙여넣기 쉽게** 정리·출력해 주는 정도면 충분하지 않을까.
- 이상적 흐름: **매월 PMS 관리 내용 → 새 시트에 붙여넣기 → 기존 엑셀 함수가 그대로 동작**.
- 즉 PMS 역할 = (a) 급여 관련 월별 데이터 입력·관리, (b) **엑셀 붙여넣기용 형식으로 내보내기**(열 순서·시트 구조를 기존 엑셀에 맞춤).

**확인 요청**
1. 위 방향이 맞나요? (PMS는 "관리+붙여넣기 보조", 계산은 기존 엑셀 함수)
2. **기존 급여관리 엑셀 파일을 공유**해 주실 수 있나요? — 시트 구조·함수·붙여넣을 **열 순서/형식**을 봐야 export를 정확히 맞출 수 있습니다.
3. PMS가 관리할 **급여 항목 범위**는 어디까지인가요? (예: 기본급·식대·차량유지비·실지급액·지급일·상태 — 어디까지 PMS 입력, 어디부터 엑셀 함수 계산?)
4. 대상 단위: **개인 월별**(사번/이름 기준)인가요? PMS 인력 마스터(pms_person)와 매핑하나요?

## 2. 계약(contracts) — 보류(합의)

유경님이 **근로계약/변경/종료** 세부 구성을 활발히 확장 중인 것으로 파악됩니다.
→ **유경님 구현이 완료·가닥이 잡히면** 그때 데이터 구조를 맞춰 진행하겠습니다. 지금은 우리 쪽 작업 보류. (확인 요청 아님)

## 3. 게시판(board) — 내부 소통 + 외부 문의 창구

**우리가 이해한 방향**
- 내부에서도 쓰지만, **권한이 없거나 거의 없는 외부 인원**이 PMS에 **문의사항을 올리면 답변**을 받을 수 있는 창구.
- **공지 형태로 게시판 상단 고정** → 사업관리쪽으로 **반복되는 질문을 선제 안내**하는 용도.

**확인 요청**
1. 위 방향이 맞나요?
2. **카테고리**: 공지 / 문의 / 일반 정도면 되나요? (상단 고정 = 공지)
3. **외부 인원 접근·권한**: 외부인도 로그인해서 글을 쓰나요? 특정 프로젝트에만 보이나요, 전사 공용인가요? 읽기/쓰기 권한 범위는?
4. **문의 답변**: 답변 주체(사업관리?)와 답변 시 **알림**이 필요한가요? (우리 알림 시스템과 연결 가능)

## 4. 체크리스트(checklists) — 개인 대시보드 할일

**우리가 이해한 방향**
- 해야 할 일을 작성해 두면 **개인 대시보드에 할일 목록**으로 뜬다.
- 각 항목은 **종료일**, **개인 매핑(담당자)**, **프로젝트 매핑**, **표시 대상(누구에게 보일지)** 을 지정.

**확인 요청**
1. 위 방향이 맞나요?
2. **표시 대상(누구에게 보일지)** 범위: 작성자만 / 담당자 / 팀 / 프로젝트 참여자 / 전체 — 어떤 선택지가 필요한가요?
3. 항목 필드 확정: 제목·종료일·담당자(개인)·프로젝트·표시대상·완료여부 — 이 외에 필요한 것(우선순위·카테고리·설명)이 있나요?
4. **개인 대시보드 표시 규칙**: 마감 임박·지연 항목 강조? 완료 항목 숨김? 정렬(마감일순)?
