### 3) 메타데이터 확장 검토

원본에는 우리 카탈로그에 없는 컬럼이 있다. 국정자원급 사업을 수용하려면 `pms_catalog_node` 또는 프로젝트별 테일러링 결과에 아래 속성이 필요하다.

| 원본 컬럼 | 현재 | 제안 |
|---|---|---|
| 관리자 / 작성 담당자 | 없음 | 산출물별 기본 책임 역할(RACI) — `pms_role_master` 참조 |
| 제출 대상 / 공문 발신 | 없음 | 발주처 제출 여부 · 공문 동반 여부 플래그 |
| 발주처 승인 / 인감 날인 | 없음 | 승인 필요 여부 · 날인 필요 여부 플래그 |
| 제출시기 | 없음 | 기한 규칙(계약 후 N일, 매주/매월, 발생시) — 알림 연동 |
