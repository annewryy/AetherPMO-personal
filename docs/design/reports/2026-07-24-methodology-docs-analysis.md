## 2. PMS 반영 계획 — 카탈로그(테일러링) 시드

현 구조 확인: `pms_catalog_node`(PHASE/ACTIVITY/TASK/DELIVERABLE 트리) + `pms_project_tailoring` 전개 — **문서의 4계층(단계>활동>작업>산출물)과 1:1 대응**. 반영 시 필요한 것:

1. **방법론(템플릿 유형) 축 추가**: OPMS/ODS/OMS/BIS 4개 방법론 루트 구분(카탈로그 노드 최상위 또는 methodology 컬럼 — 설계에서 확정).
2. **시드 마이그레이션(V15)**: ② 매트릭스 ~180행 전량 — 노드 코드(PRR/OP/1/10 체계), 산출물 문서형식, **규모별 필수/선택 3플래그**, 표준 파일명 패턴.
3. **테일러링 룰 메타**: 규모(소/중/대) 선택 시 필수 산출물 자동 표시 — ③테일러링기준·①특성표는 후속(테일러링 마법사) 설계로.
4. **용어 통일**: 메뉴·화면의 "카탈로그" → **"테일러링"** (너울님 지시, 2026-07-24).
