> 분석 기준: design 브랜치의 루트 index.html/app.js (동료 main 7128b5a 머지본, 2026-07-06).
> 목적: 동료가 "이렇게 쓰고 싶다"고 만들고 있는 기능들을 신규 버전 설계에 최대한 반영하기
> 위한 명세 소스. 상태: ✅ 반영됨 · 🔁 의도적 재설계 · 🕒 Phase 2 예정 · ❌ 미설계(백로그) · ⏸ 인증 후

## 사이드바 메뉴 전체 구조

```
Aether AI                    ← AI 포털 (랜딩)
프로젝트 관리
 ├ (대시보드)
 ├ 입찰단계                  ← 스플릿 페인: 입찰 프로젝트 + 나라장터 패널
 ├ 수행단계
 └ 나라장터 공고조회
산출물 템플릿 관리
 ├ 착수단계 템플릿
 ├ 수행단계 템플릿
 └ 종료단계 템플릿
이슈/리스크 관리
Action Item 관리
공문 관리
회의록 관리
인력관리
시스템 설정
(내 계정)                    ← 헤더 아바타에서 진입
```

## 메뉴별 기능 상세 + 반영 상태

### 1. Aether AI (AI 포털) — ❌ 미설계
- 오늘 할 일(TodayTasks), 헬스스코어(리스크순 정렬 pill/badge), 리스크 예측(우선순위 색),
  PM 추천, Copilot 서랍(drawer, 프로젝트 분석), AI 챗 위젯(bot/user 메시지)
- **판단**: 동료 버전의 간판 기능. 신규 버전 백로그에 별도 설계 필요(0007 후보).
  데이터 소스가 레거시 테이블 기반 휴리스틱이므로, pms_*로는 워크플로/전이조건 데이터를
  활용해 더 정확한 신호(예: 조건 미충족 정체 산출물)가 가능.

| 기능 | 내용 | 상태 |

| 프로젝트 목록 | 단계 서브뷰(입찰/수행), 카드/테이블 | ✅ 0004 P1-1 (필터로 흡수) |
| **입찰단계 스플릿 페인** | 좌: 입찰 프로젝트 / 우: 나라장터 공고 검색 패널(키워드, 하이브리드 캐시, 90일 확장) → "입찰 등록" 클릭 시 프로젝트 생성 | 🕒 Phase 2 — 0003 POST /projects(테일러링)와 연결. G2B 프록시(api/g2b.js)는 공용 재사용 |

| 체크리스트 | 프로젝트별 카테고리 체크리스트 모달 | 🔁 의도적 폐기 — 테일러링+산출물 status로 대체(스태시 결정) |

### 3. 산출물 템플릿 관리 — 🔁 의도적 재설계 (0004 P1-3/P1-4)
- 동료 버전: 단계(착수/수행/종료) 선택 → **템플릿 파일이 바로 나열**. 파일 업로드/삭제,
  PDF 미리보기(pdf-preview-modal), JSZip 일괄 다운로드
- 신규 버전: 분류 → 프로세스(ACTIVITY→TASK) → 산출물이 달린 구조 + 워크플로 표시(P1-3),
  산출물 평면 검색(P1-4)
- **⚠️ 갭**: 동료의 **템플릿 파일 첨부/미리보기/일괄 다운로드**는 신규 설계에 없음.
  `pms_catalog_node.template_file_ref` 컬럼은 이미 존재 → Phase 2에서 파일 스토리지
  (아마란스 원챔버 vs PMS 자체 — 제안서 ❓ 항목)와 함께 설계 필요.

### 4~7. 이슈/리스크 · Action Item · 공문 · 회의록 — ⚠️ 부분 반영
- 동료 버전: 각각 **전역 메뉴**(모든 프로젝트 횡단 목록) + 목록/상세/신규/수정/삭제 모달
  - 이슈: 유형(이슈/리스크), 우선순위(상중하), 상태(발생/조치중/완료), 검토의견
  - AI: 담당/기한/상태(대기/진행/완료), 확인 코멘트
  - 공문: 품의문/공문, 문서번호 채번, 결재라인(approval_line), 첨부파일
  - 회의록: 참석자(멤버 연동), 장소/일시/내용
- 신규 버전: 0004 P1-2의 **프로젝트 상세 탭으로만** 존재.
- **갭 2개**: ① 전역 횡단 목록 뷰 없음 — PMO는 "전체 이슈"를 한눈에 봐야 함 → 반영 필요
  ② 공문 결재라인은 아마란스 전자결재 경계(내부=아마란스 연계) → 0005/아마란스 설계와 묶어야 함 ⏸

### 8. 인력관리 — ❌ 미설계
- 참여인력 엑셀식 인라인 편집 그리드, 행 추가, 프로젝트 필터, 엑셀 내보내기
- 컬럼: 소속/직급/참여역할/PM 여부(project_members 기반)
- **판단**: pms_project_member + pms_member_availability 스키마 이미 존재. 아마란스 경계
  (내부=근태 런타임 조회, 외부=PMS 직접 관리)와 얽혀 있어 0005 이후 설계가 자연스러움 ⏸

### 9. 시스템 설정 — 낮은 우선순위
- DB JSON 내보내기/가져오기, mock 데이터 리셋, syncDb
- **판단**: 클라이언트 백업은 레거시(브라우저=DB 직결)의 산물. 백엔드 시대엔 서버측
  백업/시드로 대체 — 신규 버전에 이식하지 않음(의도적 미반영) 🔁

### 10. 내 계정 — ⏸ 인증 후 (0005)
- 프로필(아바타 이니셜/이미지/색), 알림 설정(actionItem/risk/meeting/officialDoc/artifact/
  projectOverdue 토글), 보안(비밀번호), preferences 탭
