# 상태 변경 통일 드롭다운

상태 변경 UI를 아이템(이슈·리스크·액션아이템·태스크·산출물) 상세에서 **하나의 드롭다운**으로 통일한다.
현재 상태 버튼 → **"다음으로 전환:"** 목록(지금 상태에서 갈 수 있는 상태 전부) + **"워크플로 보기"**.

## 컴포넌트(재사용)
- **`StatusMenu`**: 현재 상태 버튼(▾) → 드롭다운. targets(전환 가능 상태) 목록 렌더 — 비활성은
  사유 툴팁·🔒, 사유 코멘트 필요는 '사유' 뱃지. 하단 '워크플로 보기'. `select`·`viewWorkflow` emit(표시 전용).
- **`WorkflowViewModal`**: 전체 상태(카테고리 색·현재 강조) + 전이(from→to, 현재 상태에서 가능한 전이 강조).

## 도메인별 상태 소스
| 종류 | 전이 소스 | 실행 |
|---|---|---|
| 이슈/리스크 | 고정 사다리(발생→조치중→완료, 재오픈) | PATCH status(+사유 코멘트) |
| 액션아이템 | 고정 사다리(대기→진행→완료, 재오픈) | PATCH status |
| 태스크 | 고정 사다리(TODO→진행중→검토중→완료, 반려, 재오픈) | PATCH status |
| 산출물 | **워크플로 엔진**(GET /transitions, 조건 평가) | POST /transition(+필수 코멘트) |

- **태스크가 사다리인 이유**: seed 워크플로는 '산출물 승인' 하나뿐이고 태스크용 워크플로 정의가 없어
  엔진 전이가 0건. 태스크 status는 5종 고정셋(PATCH 허용)이라 합리적 흐름을 사다리로 노출한다.
  (후속: 태스크 워크플로를 엔진에 정의하면 산출물처럼 엔진 경로로 통합 가능.)
- **워크플로 보기 데이터**: 사다리 도메인은 사다리 맵에서 상태·전이 합성. 산출물은 기본 워크플로
  (`workflows.list` isDefault)의 statuses·transitions. 현재 상태 매칭은 code 또는 name(엔진은 코드 저장).

## 검증(2026-07-10, 로컬 dev)
태스크 상세: IN_PROGRESS 드롭다운 → 검토중·완료 + 워크플로 보기(5상태·진행중 현재·전이 흐름).
산출물 상세: 워크플로 보기(산출물 승인 — 작성중/제출/검토중/승인, 승인 현재). 산출물 APPROVED=최종 → 전이 0건.
